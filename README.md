# sundaejam.kettlekite.com

Site for Sundae Jam, a Kettlekite game. Served by GitHub Pages from `main` (domain in `CNAME`).
`assets/kk.css` and `assets/fonts/` are copied from `kettlekite-site` (`scripts/sync-shared.sh`); edit them there.
Before the first App Store submission add `privacy.html`, `terms.html` and `support.html` (see `kettlekite-vanityjam` for the shape) written from the game's real data practices.
